Put the game's MP3s in this folder with exactly these names:

  think.mp3    thinking music while buzzers are open (and during the final clue)
  correct.mp3  right answer
  wrong.mp3    wrong answer
  timeout.mp3  a timer ran out (buzz, answer or final)
  buzz.mp3     someone buzzed in (optional)

Any file that's missing falls back to a built-in tone (the thinking music just stays silent).
Only the display plays sounds, after someone taps "Tap to enable sound" on it.
